# Sources

techne uses **legally free sources only**: full texts that are free (papers, open access, public domain, official guidelines) or, for in-print books, the **author's own free material** (papers, talks, essays, official sample chapters). It never uses shadow libraries.

- **64** notes from full free texts
- **69** notes from authors' free material, each rated for how much of the book it covers
- **10** books with no legal free material (not covered)

All notes are in `skills/techne/references/books/` (index: `skills/techne/references/books/INDEX.md`). To add a book you own, put the file in `books/` and run `/techne:library ingest`.
