# Mode: copy — UX writing

Use for: microcopy, buttons, errors, empty states, onboarding, paywall copy, notifications, tooltips, confirmation dialogs.

## Principles
- Clarity over cleverness. Use the user's words, not internal jargon. Front-load the meaning (people scan the first 2 words).
- Buttons say what happens ("Start free trial", "Delete 3 photos"), not "OK/Submit".
- Errors say what happened, why, and how to fix it, without blame. Put them where the error is.
- Empty states teach and give one action.
- Paywalls and pricing: state the exact price, period, trial end and how to cancel. Honesty converts long-term; tricks inflate refunds and churn (see the ethics reference).
- Write for localization: avoid concatenated strings, allow +30–40% length, and avoid idioms.
- Keep a consistent voice: define 3 voice attributes and apply them.

## Output
For each string: the final copy, 2 alternatives with different angles (for testing), the character count, and a one-line rationale. If it's on a measurable step, suggest which variant to A/B test and the metric. If the design plugin's `ux-copy` skill is available, it can complement this mode.
