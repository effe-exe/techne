# Mode: optimize — iterate an existing flow on a big product

Use for: "improve conversion/retention/activation of X", funnel diagnosis, finding the next 10 small wins on a mature product. This is the daily data-driven loop.

## Steps
1. **Map the flow** as it is (screens + events). Ask for, or estimate, the conversion per step. Find the biggest *absolute* drop × traffic: that's where the leverage is.
2. **Diagnose why** people drop at that step. Use the friction taxonomy: they don't **understand** (clarity), don't **want** (motivation/value), **can't** (ability/effort, bugs, performance), **don't trust** it (risk), or got **distracted** (attention). Pull evidence from the matching `references/data-driven/conversion-*.md` file (onboarding, paywalls, checkout/forms, teardowns) and `references/psychology/behavior-persuasion-toolkit.md`.
3. **Generate opportunities:** for each cause, 2–3 interventions drawn from known patterns, with sources from the evidence library.
4. **Prioritize** with ICE or RICE, with confidence grounded in evidence strength ([strong]/[moderate]/[weak]). Be explicit about which ideas are bets.
5. **Package the top 3** as test briefs (→ `modes/experiment.md`) with design specs or prototypes.
6. **Ethics gate:** reject any idea that wins by deceiving the user (→ behavior/ethics reference). Offer the honest alternative.

## Output
Flow map (mermaid) with drop-offs → diagnosis → ranked opportunity table (idea, mechanism, evidence, ICE, effort) → 3 test briefs.
