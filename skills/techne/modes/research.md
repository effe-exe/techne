# Mode: research — plan and synthesize user research

Use for: deciding what to learn, interview guides, usability test scripts, surveys, synthesizing transcripts/tickets/reviews into insights, turning qual into testable hypotheses.

## Steps
1. **What decision will this research inform?** If none, don't run it.
2. **Pick the method** with `references/process/research-methods-selector.md` (attitudinal vs behavioral, qual vs quant, generative vs evaluative). Use the cheapest method that answers the question.
3. **Plan:** participants & recruiting criteria, sample size (with its limits stated), script/guide (open, non-leading, past behavior over hypotheticals — The Mom Test), tasks with success criteria.
4. **Synthesize:** atomic observations → themes (affinity) → insights ("users X because Y, which means Z") → opportunities → hypotheses for `modes/experiment.md`. Count frequency, but weigh severity. Quote users.
5. **Triangulate** with quantitative data where it exists: qual tells you why, quant tells you how many.

## Output
Research plan or a synthesis report (top insights with evidence + confidence, opportunity map, hypotheses to test).
