## What to steal (principle, 1–3 bullets)
- Render each item's metadata in the thing it describes — typeface names are set in their own typeface under every case-study thumbnail.

## Why it works
- Under each thumbnail, the fonts used are listed one per ruled row, each name rendered in that font (JAMES, Terza Reader, Lingo, Quadrant Text Mono, Sandoll 명조Neo1) — scan by look, not by name.
- Count-bearing filters inline: 'Show: All (34921) / Staff Picks (6395) / Blog (171) · Sort: Contribution Date' plus grid-density toggles.
- Corner 'Staff Pick' ribbons mark curation without a separate section.
- Chrome is quiet: RelayCond 36/700 for Collection/Blog, BentonSansRE 9–12px grey (rgb(153,153,153)) for everything else; 572 links on the fold-heavy grid.

## Where it applies / where it doesn't
- Applies: catalogues of fonts, colours, materials, products, components — anywhere the label can be a live sample.
- Doesn't: items whose attributes can't be previewed inline.
