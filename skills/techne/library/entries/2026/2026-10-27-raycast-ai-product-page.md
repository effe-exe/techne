## What to steal (principle, 1–3 bullets)
- Demo the agent mid-task, not the finished answer: show the chat with its tool state ('Reading issues… 3') and saved recurring tasks in a sidebar, and state system requirements right under the download button.

## Why it works
- Hero is three lines of Inter (48px/500, -1.92px tracking): headline, a one-sentence value line, and a single light 'Download for macOS' button with 'macOS Tahoe and Apple Silicon required' in muted text below — prerequisites disclosed before the click.
- The product window sits inside a faux macOS desktop (menu bar, live date) and shows an AI chat titled 'Fix a bug from Linear' with model label 'Claude Opus 5 High', a user message with an inline Linear chip, and a progress row 'Reading issues… 3' — tool use made visible.
- Sidebar groups prompts as reusable tasks in folders (Website: 'Keep my PRs up to date'; Personal: 'Clean up my inbox') — AI framed as repeatable routines, not one-off chats.
- Near-black rgb(7,8,10) with white at 0.4/0.7/1.0 alpha for hierarchy, red diagonal light bands as the only colour; 8-10px radii; reduced-motion CSS present.

## Where it applies / where it doesn't
- Applies: agent and automation products, any tool where trust depends on seeing what the system is doing; desktop apps with platform requirements.
- Doesn't: consumer products for non-technical users (model names and tool chips are jargon); light-themed brands.
