## What to steal (principle, 1–3 bullets)
- Make the hero a live demonstration of the core primitive (an easing curve traced by dots inside an instrument-like dial) so the product explains itself in motion before any copy.

## Why it works
- The hero is a circular instrument dial: a segmented rainbow outer ring, tick marks, a stack of red horizontal lines forming a spindle shape and a dotted S-curve tracing an easing function — the library's subject (timing) drawn as a gauge.
- Headline 'All-in-one animation engine.' in DIN 700 at ~64px (line-height 0.86) on warm charcoal #252423; subline 'A fast and flexible JavaScript library to animate the web' with a small red underline accent.
- Nav is a monospace face at 12px/600 uppercase (DOCS, EASINGS, LEARN + CodePen/GitHub icons, red 'SPONSOR' button); bottom-left an 'npm i animejs' chip with copy icon and an outlined 'LEARN MORE ↓'.
- Text colours borrow a code-editor palette (blue #61AEEE, orange #D19A66, green #98C379, grey #ABB2BF), tying marketing to the syntax users will write; red #FF4B4B is the brand signal (196 surfaces). No reduced-motion CSS detected.

## Where it applies / where it doesn't
- Applies: Libraries, engines and tools whose core concept is abstract (timing, physics, layout): visualise the concept as an instrument.
- Doesn't: Products where a decorative gauge would imply measurement that isn't real (finance, health dashboards).
