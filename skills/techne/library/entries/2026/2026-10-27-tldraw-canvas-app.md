## What to steal (principle, 1–3 bullets)
- Keep the canvas 100% content: tools float in one bottom-centre dock, and the style panel exposes every option as a small visual swatch grid (colour, fill, dash, size S/M/L/XL) rather than dropdowns.

## Why it works
- Opens directly to a usable blank canvas — no landing page, no sign-up wall; 'Sign in to share' only appears where sharing needs it (top-right blue button).
- Bottom dock of ten tools (select highlighted in blue, hand, draw, eraser, arrow, text, note, image, rectangle, more) with a secondary row of undo/redo/delete/duplicate above it.
- Style panel is a 4x3 grid of 12 colour dots, an opacity slider, fill-style and dash-style icons, and S/M/L/XL size chips — every choice is visible and one click.
- Monochrome chrome (rgb(46,46,46) on rgb(249,250,251)) with 9px radius buttons; zoom readout '100%' in bottom-left corner; 'Build with the tldraw SDK' upsell is a dismissible dashed-outline note.

## Where it applies / where it doesn't
- Applies: Canvas, diagram, design and annotation tools; any editor with a finite set of visual styles.
- Doesn't: Tools with open-ended styling (full colour pickers, typography) where a fixed grid becomes limiting.
