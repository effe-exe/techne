## What to steal (principle, 1–3 bullets)
- Serve both the new and the existing user from the hero: a platform-detected split download button (with a dropdown for other OSes) plus a one-line escape hatch — 'Already have Visual Studio Code? Open now'.

## Why it works
- Hero split into two bordered columns on rgb(13,17,23): left a mono eyebrow 'GITHUB COPILOT' with a green block cursor and Mona Sans 56/440 'Command your craft'; right the value line and actions.
- Green split button 'Download for Linux | ▾' (OS-detected, other platforms in the caret), grey secondary 'See plans & pricing', and a link for users who already have the host editor.
- A sticky product subnav (Desktop App, Copilot in VS Code, Agents on GitHub, CLI, Code Review, For Business, Tutorials, Plans & Pricing) makes a sprawling multi-surface product navigable.
- Product window below shows the app: Home / My work / Automations / Search, sessions grouped by repo with PR status badges, and a prompt that teaches syntax ('type / for commands or # to reference issues'). Reduced-motion CSS present; easings cubic-bezier(0.16,1,0.3,1) expo-out.

## Where it applies / where it doesn't
- Applies: products available on many platforms or inside host apps (plugins, extensions, CLIs); any page with a mixed new/returning audience.
- Doesn't: single-platform apps; the event promo bar and two nav tiers add noise — keep only one.
