## What to steal (principle, 1–3 bullets)
- State availability as part of the identity ('Independent developer, available Dec. 2026'): the one fact a client needs, on the first screen.

## Why it works
- The work is a horizontal strip of narrow vertical slits, each a grayscale crop of a project (fashion portraits, architecture, landscape), offset to the right on #141414, like a contact sheet seen through blinds.
- A top-centre ruler of about 30 tick marks acts as a scrub and progress indicator; the logotype 'ARISTIDE' is set in a condensed face (TNY, 50px, line-height 0.88).
- Bottom corners carry the only text: 'INDEPENDENT DEVELOPER / AVAILABLE DEC. 2026' left; 'EMAIL / INSTAGRAM / TWITTER' right, in about 11px caps (jws face). Sage text rgb(186,196,184), one mustard accent rgb(204,153,51).
- WebGL; the HTML is only 'Please enable JavaScript to view this website.', so there is no fallback content.

## Where it applies / where it doesn't
- Applies: Freelancer and studio portfolios; the availability line transfers to any services site.
- Doesn't: No JS fallback, about 11px text, and no reduced-motion CSS; not for content that has to be found or read.
