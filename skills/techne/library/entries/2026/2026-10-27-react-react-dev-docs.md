## What to steal (principle, 1–3 bullets)
- Split docs into two doors — Learn (narrative, ordered) and Reference (lookup) — and make that choice the primary CTA pair on the homepage.

## Why it works
- Hero: logo, 'React' in Optimistic Display 52/600, one-line definition, then two pill buttons 'Learn React' (filled teal) and 'API Reference' (outlined) — the IA is the CTA.
- Header: version tag 'v19.3', a wide search field with Ctrl K, Learn / Reference / Community / Blog, dark mode, language and GitHub icons.
- Typography: Meta's Optimistic Text for prose (120 nodes) and Source Code Pro for code (165 nodes) — code is the majority text on the page.
- Section 'Create user interfaces from components' starts on a grey rgb(246,247,249) band; pills 9999px, 8–24px cards; reduced-motion honored.

## Where it applies / where it doesn't
- Applies: any product with both newcomers and experts; SDK and API docs.
- Doesn't: tiny tools where a single page suffices.
