## What to steal (principle, 1–3 bullets)
- Demo the agent explaining its reasoning in plain language — reproduce, trace, name the root cause, propose the fix — and then list every surface the same agent lives in (Terminal, Web, iOS, Android, GitHub, VS Code, JetBrains, Slack) as equal tiles.

## Why it works
- Left column: anthropicSerif 64/500 'Claude Code', a 23px/1.5 subhead naming task sizes ('a bug fix, test, or multi-day migration') and control surfaces ('Steer and review from your terminal, IDE, Slack, or web'), a full-width black 'Download for Linux' and a beige 'Read documentation ↗', then 'Available for macOS, Linux, and Windows.'
- Right: app window with Projects, Pinned, Scheduled ('Weekly dependency audit') and Recents; the thread shows a user report in a blue bubble, then the agent's steps ('Read 3 files…', 'Ran agent · Reproduce the double-submit…') and a root-cause paragraph naming `createCharge()` and the idempotency-key bug.
- Composer footer exposes mode ('Auto'), model ('Opus') and effort ('Extra high') as quiet text controls — power settings visible but not loud.
- 'Other ways to use Claude Code:' row of eight equal square tiles with platform icons; shared Claude palette (paper rgb(250,249,245), ink rgb(20,20,19)); reduced-motion CSS present.

## Where it applies / where it doesn't
- Applies: agent products and any tool spanning many surfaces; debugging/support tools where explanation builds trust.
- Doesn't: consumer apps where model/effort controls are jargon; tile rows of logos fail when surfaces differ in capability (say so).
