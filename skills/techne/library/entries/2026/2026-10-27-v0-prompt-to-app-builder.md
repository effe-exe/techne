## What to steal (principle, 1–3 bullets)
- Defeat the blank prompt with three layers of scaffolding under one input: example chips with a shuffle button, then a template gallery with social proof (remix and like counts) — users can start by typing, picking, or forking.

## Why it works
- Hero = the tool: 'What do you want to create?' in GeistSans 32/600 at -1.28px, an input with model picker ('v0 Max'), mic and send, then four outlined chips (Contact Form, Image Editor, Mini Game, Finance Calculator) and a ↻ refresh to shuffle examples.
- 'Start with a template' grid below shows real community outputs with author avatar, remix count and likes (e.g. 14.7K / 2.1K) — examples double as proof of quality.
- Pure Geist neutrals: rgb(250,250,250) ground, rgb(23,23,23) ink, rgb(77,77,77) secondary; 6-8px radii, hairline borders; no colour except inside user-generated thumbnails, so the output is the colour.
- Motion is standard 0.15s cubic-bezier(0.4,0,0.2,1); reduced-motion CSS present.

## Where it applies / where it doesn't
- Applies: generative tools, template-driven products, any creation tool facing blank-canvas paralysis.
- Doesn't: products where remix counts would be meaningless or gameable; a pure-neutral UI can feel anonymous for consumer brands.
