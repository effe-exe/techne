## What to steal (principle, 1–3 bullets)
- Turn the sidebar into the capability map — each agent mode (scheduled tasks, deep research, slides, docs, 3D) is a nav item — so the empty input stays calm while discoverability lives one glance to the left.

## Why it works
- Logged-out visitors land in the app: one centred input with placeholder '尽管问，或做个 Agent 任务…' ('Ask anything, or do an Agent task…'), '+' attach, send, and a tray below with 选择项目 (choose project) and 插件 (plugins).
- Sidebar lists modes as first-class destinations: 我的 Kimi, 插件, 定时任务 (scheduled tasks), 灵感库 (inspiration library), 3D Make 'New', PPT, 深度研究 (deep research), 文档 (docs) — capabilities are browsable, not hidden behind slash commands.
- '新建会话' (new chat) button shows its shortcut 'Ctrl K' inline as keycaps; skeleton loaders hold the projects list while it loads.
- Warm off-white rgb(251,250,249) canvas framing a white rounded panel, black at 90/60/45% alpha for text hierarchy, 8-20px radii; system font; 0.15-0.3s ease; reduced-motion CSS present.

## Where it applies / where it doesn't
- Applies: multi-mode AI assistants and tools with many verbs; products whose users scan rather than type commands.
- Doesn't: single-purpose tools — a long mode list becomes a feature dump; needs pruning as modes grow.
