## What to steal (principle, 1–3 bullets)
- Manage many AI agents like a team's work, not like chats: a board with Running / Waiting for review / Done columns, each card carrying a plain-language status ('Working…', 'PR is ready', 'Waiting for CI') and age.

## Why it works
- Hero is a 40px nbInternationalPro headline (-1.2px, line-height 1.04), a two-line grey subhead and one black 200px-radius 'Download for Linux' pill (OS-detected); a monospace uppercase bordered callout ('THE HOME FOR EVERY AGENT YOU RUN — LEARN MORE →') is the only secondary.
- The product shot is the argument: sidebar (New session, Automations, Security, Review, Wiki) plus a Sessions board with Board/List toggle, filter chips (Status, Space, Pull request, Agent) and three status columns with counts.
- Cards use tiny state glyphs and text rather than colour alone — blue dot for unread, green PR icon, 'Waiting for CI', '42m ago' — so agent state is legible at a glance and accessible to colour-blind users.
- White/rgb(248,248,248) surfaces, rgb(25,25,25) ink at 56% for secondary, green rgb(31,157,85) success; no prefers-reduced-motion CSS detected.

## Where it applies / where it doesn't
- Applies: any product running parallel background jobs (agents, renders, builds, imports) where humans review results.
- Doesn't: single-task assistants; consumers who don't think in queues.
