## What to steal (principle, 1–3 bullets)
- Ship components as code users own, and showcase them as a dense grayscale wall of real product fragments so the reader imagines their own brand on top.

## Why it works
- Centered hero in Geist 48/600 at -2.4px tracking ('The Foundation for your Design System') with black pill 'Get Started' and grey pill 'View Components'.
- Below: a masonry of live components in pure grayscale (bar chart of greys, milestone form, QR card, chat, button group) — no brand color, so it reads as neutral foundation.
- Nav exposes the model: Docs / Components / Blocks / Charts / Directory / Create — from primitive to composed block to generator.
- Colors expressed in lab() greys; radii 8–10px controls, 18–24px cards; inputs are filled grey without borders.

## Where it applies / where it doesn't
- Applies: component libraries, starter kits, any product meant to be themed by its users.
- Doesn't: brand-led marketing where neutrality reads as absence of identity.
