## What to steal (principle, 1–3 bullets)
- Prove a component library with realistic composed screens (team list, notifications, invoice) instead of isolated buttons.

## Why it works
- Serif display 'Start building your app now' in Adobe Text Pro 78/400, line-height 0.9, -3.9px tracking — an unexpected editorial voice for a component library.
- Right side is a wall of live cards built with the library (Your team, Notifications with toggle rows, Sign up, Company card, Invoice paid) over a pale blue-pink gradient.
- Code snippet card (import Theme, Button) and dark 'Get started' / tinted 'Playground' buttons; Themes / Primitives / Icons / Colors as top-level product tabs.
- Text uses alpha colors (rgba(0,7,20,0.624)) from the Radix 12-step scales; radii 4/6/8/12px; transitions 140–180ms.

## Where it applies / where it doesn't
- Applies: component libraries, UI kits, any B2B tool that can show itself composing real screens.
- Doesn't: when the showcase content is generic placeholder data, it reads as a template.
