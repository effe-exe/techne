## What to steal (principle, 1–3 bullets)
- Annotate your own page with the tool that built it: tiny mono labels show the exact classes behind each headline, so the marketing page is also the tutorial.

## Why it works
- Above the 96/400 Inter H1 (-4.8px tracking) a faint plexMono caption reads 'text-8xl text-gray-950 tracking-tighter text-balance' — the page documents itself.
- Visible hairline layout grid with hatched gutters frames every row; content sits inside the guides like a spec sheet.
- Code-highlighted utilities (flex, pt-4, text-center, rotate-90) inline in body copy in sky blue; hero pairs a dark editor with a live rendered card it produces.
- 'Quick search Ctrl K' sits next to the primary CTA, not just in the nav; version switcher 'v4.3' by the logo.

## Where it applies / where it doesn't
- Applies: devtools, design tools, any product whose output can be shown alongside its input.
- Doesn't: non-technical audiences; the annotation layer reads as noise if the reader can't parse code.
