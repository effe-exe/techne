## What to steal (principle, 1–3 bullets)
- Lead with the metric that reframes the category: an 'Agent traffic 78.2766%' badge above the headline says docs readers are now mostly machines.

## Why it works
- Eyebrow badge 'Agent traffic' with a green mono value '78.2766%' sits above the H1 — a live-looking metric as the hook.
- Headline 'The intelligent documentation platform' in Arizona Flare serif 50/400 at -4% tracking, sub-line bolding 'startups', 'enterprises', and 'agents'.
- Right side: the product itself (a docs site with Ask Assistant, Quickstart, AI optimization nav; API Reference / Libraries / Changelog tabs) emerging from green line-wave graphics; floating 'Ask assistant' button.
- Inter UI, Paper Mono accents; lab() color tokens, green brand; 4–12px radii; reduced-motion honored.

## Where it applies / where it doesn't
- Applies: B2B tools whose market shifted (AI, mobile, regulation) and need to say so in one number.
- Doesn't: if the metric isn't real or explained, a precise-looking number is a credibility risk — source it.
