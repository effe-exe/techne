## What to steal (principle, 1–3 bullets)
- Carry the product's imperfection into the UI — uneven, hand-cut display type, tilted frames and stepped animation — so the site feels like the wrapper.

## Why it works
- Saturated red page rgb(235,0,0) with a lowercase slab nav ('choco shop', 'custom wrappers', 'our promise'); display type is uneven and hand-cut, photos sit in tilted white frames.
- Motion uses steps(2)/steps(3) easings (26 transitions) — a deliberate stop-motion jitter rather than smooth curves.
- Cookie dialog: 'Deny' (blue), 'Allow selection', 'Allow all' (yellow) are the same size; optional toggles start off. Fonts: American Typewriter + 'Chocolate letter'.

## Where it applies / where it doesn't
- Applies: Brands with a physical signature (packaging, illustration) that can become a UI rule.
- Doesn't: Neutral or enterprise products; stepped motion can read as broken if the brand doesn't explain it.
