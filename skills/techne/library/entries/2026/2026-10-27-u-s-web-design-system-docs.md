## What to steal (principle, 1–3 bullets)
- Start with provenance: the 'An official website of the United States government — Here's how you know' banner is a reusable trust pattern for any site impersonation could target.

## Why it works
- Top banner with flag and expandable 'Here's how you know' explains .gov and HTTPS — trust established before content.
- Header carries versioned download 'Download v3.14.0' and 'Read website standards' as outlined buttons; secondary nav How to use / Design principles / Components / Patterns / Design tokens / Utilities / Templates.
- Public Sans throughout (H1 36/200 light, 17/700 subheads); four red circular icon cards (Components, Patterns, Design tokens, Utilities) each with a plain-language summary and an underlined action link.
- Square-ish buttons with 4px radius, red and blue rgb(38,114,222) CTAs 'Introducing USWDS 3.0' / 'Migrating to USWDS 3.0'; links rgb(0,94,162); reduced-motion honored.

## Where it applies / where it doesn't
- Applies: government, healthcare, finance, education — any site where users must verify authenticity.
- Doesn't: brand-expressive marketing; the system is deliberately conservative.
