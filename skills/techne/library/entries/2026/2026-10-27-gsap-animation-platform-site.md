## What to steal (principle, 1–3 bullets)
- Swap a few letters of the headline for animated shapes (a pinwheel dot, a lightning-bolt 't', a squiggle) so the type itself demonstrates 'Animate anything'.

## Why it works
- 'Animate anything' set huge (~240px) in cream #FFFCE1 Mori on near-black #0E100F, with letters replaced or decorated by colourful shapes: a gradient pinwheel above the 'i', a sunburst in the 'a', a green lightning bolt as the 't', a lilac squiggle under 'hing'.
- A full-width green gradient announcement bar states the big news plainly: 'GSAP is now free for everyone, thanks to Webflow's support!'
- Positioning line wrapped in giant curly braces '{ GSAP – A wildly robust JavaScript animation library built for professionals }' — code syntax as a graphic device; outlined green 100px-radius 'Get GSAP ⊕' CTA.
- Rich easing vocabulary in CSS (cubic-bezier(0.645,0.045,0.355,1), (0.86,0,0.07,1), (0.23,1,0.32,1)); no reduced-motion CSS detected.

## Where it applies / where it doesn't
- Applies: Brands selling a capability that can be shown in the logotype or headline (motion, type, 3D, colour).
- Doesn't: Text-critical surfaces; substituted glyphs hurt readability and screen-reader output if not handled with real text.
