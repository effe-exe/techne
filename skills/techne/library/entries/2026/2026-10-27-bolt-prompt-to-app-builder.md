## What to steal (principle, 1–3 bullets)
- Beside the blank prompt, offer the user's existing material as a starting point — 'or start from Figma / GitHub / Team template' — plus an output-type picker (Website, Slides, App, Prototype); importing beats imagining.

## Why it works
- 'What will you build today?' in Schibsted Grotesk 48/600 (-1.2px) over a blue light-bloom panel; a dark 1040px input with a pre-filled example ('Let's build a KPI dash'), a 'Plan' toggle (think before building) and 'Build now ▶'.
- Four square tiles below choose output type (Website, Slides 'New', App, Prototype) — framing the request before typing.
- 'or start from' row with Figma, GitHub and Team template chips gives non-prompt entry points for teams with existing work.
- Dark rgb(23,23,25) ground, off-white rgb(249,246,249) text, one saturated blue for 'Get Started'; WebGL glow but reduced-motion CSS present; Silkscreen pixel font as a playful accent.

## Where it applies / where it doesn't
- Applies: generators and builders whose users usually have prior assets (designs, repos, docs, spreadsheets).
- Doesn't: the blue-glow dark hero is a commodity look in 2026 AI landing pages — steal the entry points, not the aesthetic.
