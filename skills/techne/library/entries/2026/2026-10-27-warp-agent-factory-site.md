## What to steal (principle, 1–3 bullets)
- Visualise parallel agent work as a live status grid with an explicit legend and running totals ('224 tasks · 15 active · 1,422 PRs shipped') — an honest, data-shaped hero instead of an illustration.

## Why it works
- Headline set entirely in azeretSemiMono 54px (-2px tracking, line-height 1.05) — a monospace display face makes 'infrastructure' feel engineered; nav and buttons in uppercase mono 12-13px.
- Hero figure framed like a technical drawing: '[ fig. 1 — the factory ]' caption, inner '[ FIG. T4 · THE FACTORY ] … 8 × 28 · LIVE', a grid of 224 squares where electric-blue rgb(42,30,255) cells are working; legend Queued / Working / Waiting / Shipped and totals sit beneath.
- Off-white oklch(0.99…) ground with faint dot-grid, ink rgb(26,21,34) at 62%/40% alpha for hierarchy; one blue and one lime 'BOOK A DEMO' accent; vertical 'WARP · HOME · 2026' marginalia.
- 965 transitions on cubic-bezier(0.4,0,0.2,1); WebGL used but prefers-reduced-motion CSS present; a sound toggle is offered bottom-left rather than autoplaying audio.

## Where it applies / where it doesn't
- Applies: infra, agent and ops products whose story is throughput and status; any dashboard hero that can show real (or realistic) live data.
- Doesn't: consumer or emotional products — all-mono type is cold and less readable for long copy; avoid fake 'live' numbers that aren't real.
