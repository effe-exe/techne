## What to steal (principle, 1–3 bullets)
- Make the product the homepage: a single question ('What do you want to know?') and one input, with modes as a segmented toggle inside the box and two explanatory cards below — no marketing page between intent and answer.

## Why it works
- Logged-out visitors land directly in the app: centred 26px pplxSans heading, a 768px-max input with 'Search | Computer' segmented toggle, model picker, mic and voice button inside the field — every capability is discoverable from the input itself.
- Two cards under the box ('Search anything' / 'Get work done with Computer — NEW') explain modes in one line each, doing onboarding without a tour.
- Restrained palette: off-white rgb(251,251,251), deep teal ink rgb(11,40,51) and one brand teal rgb(1,106,113); 9999px pill controls, 8-12px cards; 0.15-0.3s ease-out transitions, prefers-reduced-motion CSS present.
- Cookie notice offers 'Decline optional' at equal size and weight to 'Got it' — consent without a dark pattern.

## Where it applies / where it doesn't
- Applies: any tool whose value is instantly demonstrable from one input (search, converters, generators, calculators).
- Doesn't: products that need context or setup before a first useful result; complex B2B tools where a blank box is intimidating.
