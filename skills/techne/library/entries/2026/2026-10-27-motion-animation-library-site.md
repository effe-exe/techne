## What to steal (principle, 1–3 bullets)
- Put the install command, with a copy button, right next to the primary CTA, so 'Get started' is a one-paste action for developers.

## Why it works
- The fold is a particle sphere of gold/orange dots on near-black #0E1312, with the headline 'The animation library loved by humans and agents alike.' bottom-left in TASA Orbiter 700 at ~35–40px (tracking -1.2/-1.4px).
- Bottom-right: an outlined field 'npm install motion && npx motion-ai' with a copy icon beside a yellow 'GET STARTED >' button, and the line 'Free and open source. Previously Framer Motion.' — rename continuity handled in six words.
- Navigation and buttons are Geist Mono 11px uppercase with 0.88px tracking (DOCS, EXAMPLES, AI KIT, MOTION+); colours in OKLCH (text oklch(0.94 0.008 96), secondary oklch(0.69 0.012 148)).
- Easings are expo/quart-out (cubic-bezier(0.25,1,0.5,1), cubic-bezier(0.16,1,0.3,1)) at 0.15–0.2s — the motion library demonstrates the curves it sells.

## Where it applies / where it doesn't
- Applies: Developer tools, SDKs, CLIs: anything whose first step is an install command; products that went through a rename.
- Doesn't: Non-technical audiences, for whom a terminal command is a barrier, not a shortcut.
