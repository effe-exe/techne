## What to steal (principle, 1–3 bullets)
- Make brand guidelines self-demonstrating: the page is drawn on its own visible blueprint grid, so the layout system is shown before it is explained.

## Why it works
- Fold is a white field divided by thin light-blue hairline columns and rows; the only content is a 4-line headline in Dropbox blue rgb(0,97,254) set in the brand's Sharp Grotesk (Dbsharpgroteskvariable) and a blue double-chevron scroll cue.
- Text and links use the brand blues (rgb(0,97,254), rgb(95,157,255)) with warm grey rgb(115,108,100) for body — the colour system is visible in the UI itself.
- Slow, deliberate 1.5s ease-in-out transitions on 32 elements suggest staged reveals as you scroll.
- Cookie dialog offers 'Decline' (outlined) beside 'Accept All' (solid) plus 'Customize cookies'.

## Where it applies / where it doesn't
- Applies: Design systems, brand portals, documentation that should embody the system it describes.
- Doesn't: Task-oriented docs where users need content immediately — the mostly empty fold costs clarity; only the first viewport was observed.
