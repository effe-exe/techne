## What to steal (principle, 1–3 bullets)
- Illustrate a collaboration system with collaboration itself: named live-style cursors (including the AI agent) hovering over the headline.

## Why it works
- 'Better teamwork by design.' in Atlassian Sans 112/700 on a dot grid, with 'design.' in blue rgb(24,104,219); three cursor flags 'Tony', 'Kyah' and 'Rovo' (Atlassian's AI) — human and agent presence in one metaphor.
- Left side scroll-progress dots (8) mark sections; header is just Design system / News / Search / Theme.
- Atlassian Sans + Atlassian Mono (32 nodes) as a paired family; brand color blocks (blue, green rgb(148,199,72), orange rgb(252,167,0), purple) appear below the fold.
- Motion uses springy cubic-bezier(0.4,1,0.6,1) at 50ms–0.7s; reduced-motion honored.

## Where it applies / where it doesn't
- Applies: collaboration products, design systems with a brand-refresh story.
- Doesn't: content-heavy docs where giant display type pushes guidance below the fold.
