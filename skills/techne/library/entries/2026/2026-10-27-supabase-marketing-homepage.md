## What to steal (principle, 1–3 bullets)
- Sell a platform as a grid of primitives: one card per capability, each with a one-line promise, three checkmarks and a tiny animated diagram of what it does.

## Why it works
- Two-tone headline 'Build in a weekend / Scale to millions' in Manrope 46/500, second line in brand green; sub-copy lists the platform pieces in one sentence.
- Bento grid: Postgres Database (large, with line-drawn elephant and 3 checks), Authentication (blurred email list), Edge Functions (CLI pill 'supabase functions deploy' over a wireframe globe).
- Three families with roles: Manrope headings, Inter UI 14, Source Code Pro for data/CLI (44 occurrences) — mono text signals 'real data' inside illustrations.
- Colors defined in oklch (bg oklch(0.995 0 337.5)), green CTA rgb(21,89,59)-family; ~8.9px button radii, cards ~16px; reduced-motion query present. Captured in light theme (headless default).

## Where it applies / where it doesn't
- Applies: multi-product platforms; any feature overview where each capability needs equal weight.
- Doesn't: single-feature products; bento grids get generic when cards lack a specific diagram.
