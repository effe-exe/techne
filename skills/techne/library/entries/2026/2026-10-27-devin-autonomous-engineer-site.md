## What to steal (principle, 1–3 bullets)
- Make an autonomous agent's output auditable: end every task with a proof card — PR summary in plain language, diff size, '5 tests passed', and a playable test recording of the agent using the feature in a real browser.

## Why it works
- Headline in nbInternationalPro 40/400 (-1.2px): 'Meet Devin, your team's autonomous software engineer', with a subhead that states the stopping rule — 'won't stop until the PR is ready to merge'.
- Product shot shows the full loop: the human's brief ('Follow our existing auth patterns…'), collapsible step log ('Explored authentication across 3 repositories', 'Implemented SSO… +13 −1'), Devin's reply, and 'Tested sign-in and account linking in the browser — 5 tests passed' in green.
- A right-hand PR card ('PR Open · acme/platform #2922', 12 files changed +8 −14, 'Devin's analysis') embeds a 'Test recording on Mac OS X virtual environment 2/5' video — evidence, not assertion.
- Same restrained system as Devin Desktop: white/rgb(248,248,248), ink rgb(25,25,25) at 56%/40%, 200px pill CTAs; reduced-motion CSS present.

## Where it applies / where it doesn't
- Applies: any agent or automation that acts on the user's behalf (code, ops, finance, data cleanup) — attach artefacts that let a reviewer verify in seconds.
- Doesn't: instant, low-stakes outputs where proof cards are overhead.
