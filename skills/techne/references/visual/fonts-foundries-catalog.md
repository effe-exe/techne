# Fonts & Foundries Catalog (with licensing notes)

> **Use this when:** recommending a typeface, finding alternatives to an expensive or overused font, checking whether a font can legally be used in an app, website, ad or Figma file, or looking for real-world typographic references.
> **Skip when:** you only need sizing/spacing rules (see `typography.md`).
> **Output:** a shortlist of 2–4 faces with a reason, the license type needed, and a free fallback.

---

## 0. How to use this catalog (agent rules)

1. **Start from the job, not the font.** Is it a dense tool, a consumer app, an editorial product or a brand-led marketing site? Pick the category, then the face.
2. **Always give a free/open fallback** next to a commercial pick, so the designer can prototype now and license later.
3. **Never assume a license.** Name the license type the use needs (desktop, web, app, ad/broadcast, ePub, logo/trademark) and tell the user to confirm on the foundry's EULA page. Prices and terms change; this file doesn't track prices.
4. **Trial fonts are for pitching only.** Most foundries (Klim, Grilli, Dinamo, Pangram Pangram, Commercial Type and others) offer trial files that forbid production, client delivery or public release.
5. **Catalog facts may drift.** Family lists below are well-known flagships. Where uncertain they're marked *(verify)*. When network access exists, check the foundry site before final recommendation.
6. **Overuse is a real cost.** A face seen everywhere (e.g. some PP and ABC grotesks in 2020s startup sites, or Inter in SaaS) signals "template". That's fine for tools, and a problem for brands that need distinction.

## 1. License types: what each use needs

| Use | License usually needed | Gotchas |
|---|---|---|
| Designing mockups in Figma/desktop apps | **Desktop** (per user/seat) | Every designer on the file needs a seat, or uses Figma's shared org fonts with a valid license |
| Website / web app | **Web** (often pageview- or traffic-tiered) | Self-hosting usually required. Some foundries count monthly pageviews or unique visitors |
| Native iOS/Android app | **App / mobile embedding** (per app, sometimes per install tier) | Web licenses usually do NOT cover apps |
| Ads, social video, TV | **Broadcast / digital ads** | Often a separate license |
| E-books, PDFs | **ePub / digital publication** | |
| Logo / wordmark | Usually covered by desktop, but *modifying* glyphs may need permission | Check "modification" clauses |
| SaaS where users create content in the font (e.g. a design tool) | **Server / OEM / SaaS** | Expensive and negotiated. Don't assume web covers it |

**Open licenses**
- **SIL Open Font License (OFL):** free for commercial use, including embedding in apps and sites, and modifying. You can't sell the font by itself, and modified versions may not use a Reserved Font Name. Most Google Fonts are OFL.
- **Apache 2.0:** free and permissive (Roboto, older Google fonts).
- **Fontshare (Indian Type Foundry) license:** free for personal and commercial use per their terms (verify per family).
- **Apple system fonts (SF Pro, SF Compact, SF Mono, New York):** licensed for designing and building UI *for Apple platforms*. Not for Android, general web branding or print (Apple Font License; verify current terms). For web, use `system-ui` / `-apple-system` so the user's OS renders it legally.
- **Segoe UI:** a Windows system font, not licensed for redistribution on the web. Reference it via local font stacks only.

## 2. Independent foundries (premium, high craft)

### Klim Type Foundry (Wellington, NZ; Kris Sowersby)
- **Söhne**: an Akzidenz-style grotesk, a favourite for refined product UI and marketing. **Söhne Mono** and Breit/Schmal widths are also available.
- **Tiempos** (Text/Headline/Fine): editorial serif, excellent for reading products.
- **Untitled Sans / Untitled Serif**: deliberately "neutral" faces, very good for UI.
- **Founders Grotesk**, **National 2**, **Domaine** (Display/Text/Sans), **Calibre**, **Financier**, **Epicene**.
- Notes: exceptional design essays on each family's site page (good learning material). Trial fonts are available. Licenses are clear and separated by medium.

### Commercial Type (NY/London; Paul Barnes & Christian Schwartz)
- **Graphik**: a workhorse grotesk for product + brand. **Graphik Compact/Condensed/Wide** extends it.
- **Atlas Grotesk / Atlas Typewriter**, **Lyon Text/Display** (serif for reading), **Publico** (news serif), **Canela** (high-contrast display), **Druk** (ultra-condensed display; heavily used in sports and fashion), **Austin**, **Caponi**, **Dala Floda**, **Portrait**, **Robinson**.
- Notes: strong for editorial products. Druk is only for display sizes.

### Grilli Type (Lucerne, CH)
- **GT America** (grotesque + gothic hybrid, many widths), **GT Walsheim** (friendly geometric, widely used in consumer tech), **GT Standard** (a systematic family with widths and a mono), **GT Alpina** (serif with lots of styles), **GT Sectra** (sharp, calligraphic serif), **GT Super** (display serif), **GT Eesti**, **GT Flexa** (variable widths), **GT Pressura** (stencil-mono-like), **GT Maru** (rounded), **GT Planar**, **GT Zirkon**.
- Notes: excellent variable fonts and playful microsites. Trial program available.

### Dinamo (Berlin/Basel; "ABC" prefix)
- **ABC Diatype** (neutral grotesk + Mono + Rounded, etc.), **ABC Favorit** (quirky grotesk, very 2020s), **ABC Monument Grotesk**, **ABC Whyte** (with Inktrap), **ABC Ginto**, **ABC Oracle**, **ABC Arizona** (sans-serif ↔ serif "flare" axis), **ABC Gravity**, **ABC Social**.
- Notes: technically advanced, with variable and experimental axes. Very visible in design-studio and startup branding, so watch overuse. Also offers custom typography services.

### Colophon Foundry (London/LA)
- **Aperçu** (+ Mono), **Basis Grotesque**, **Value Sans/Serif**, **Raisonné**, **Reader**, **Castledown** (school-literacy origin, friendly), **Mabry**, **Montefiore**, **Burgess**, **Lisbon**.
- Notes: solid UI-capable grotesks with character.

### Production Type (Paris; Jean-Baptiste Levée)
- **Spectral**: a screen-first serif, *free via Google Fonts (OFL)*. It is one of the best free reading serifs.
- Retail and custom catalog includes sans, serif and display families with large language coverage; they also have major corporate and custom work *(browse productiontype.com for current retail families; verify names before recommending)*.
- Notes: a strong choice when you need multi-script and high-craft bespoke type.

### Displaay Type Foundry (Prague; Martin Vácha)
- **Roobert** (geometric-ish grotesk with personality; a popular tech/brand face), plus several display and text families *(e.g. Gogh, Hellix, Saans: verify foundry attribution and current catalog)*.
- Notes: contemporary, affordable, many variable fonts.

### Pangram Pangram Foundry (Montreal)
- **PP Neue Montreal** (clean neo-grotesk), **PP Editorial New** (high-contrast editorial serif, *very* trendy), **PP Mori**, **PP Formula** (condensed display), **PP Right Grotesk**, **PP Monument Extended**, **PP Neue Machina**, **PP Object Sans**, **PP Radio Grotesk**, **PP Fragment**.
- Notes: personal-use trials are free to download (their "free for personal use" model). Commercial use needs a license. These faces are extremely common in 2020s portfolio and startup sites, so they distinguish less than they used to.

### Sharp Type (New York; Lucas & Chris Sharp)
- **Sharp Grotesk** (many widths/weights), **Sharp Sans**, **Ogg** (calligraphic display serif), **Beatrice** (and Beatrice Display), **Sharp Slab** *(verify)*, plus big custom work for brands.
- Notes: expressive, fashion- and culture-forward. Good for brand display.

### Other independents worth knowing
- **Lineto** (Zurich): Circular (the ur-"startup geometric"), Akkurat, Brown, Replica, Riforma, Gramatika.
- **Swiss Typefaces**: Suisse Int'l / Works / Screen (Suisse Screen is tuned for UI), Euclid *(verify foundry)*.
- **Optimo**: Theinhardt, Cargo, Romie *(verify)*.
- **Milieu Grotesque**: Maison Neue (+ Mono), Generika, Chapeau.
- **Frere-Jones Type**: Retina (designed for tiny financial data), Mallory, Exchange, Empirica.
- **Hoefler&Co (now Typography.com; owned by Monotype since 2021)**: Gotham, Ringside, Sentinel, Mercury, Whitney, Archer, Chronicle.
- **OH no Type Co** (James Edmondson): fun display families, very good type-design writing.
- **Future Fonts**: a marketplace for in-progress fonts at lower prices, which grow into full families.
- **Velvetyne**, **Collletttivo**, **Open Foundry**: libre/open-source experimental faces (check each license).
- **Type Network**, **Fontstand** (rent fonts monthly), **I Love Typography** (ILT store + essays).

## 3. Large foundries / platforms

### Monotype (incl. Linotype, ITC, Bitstream, Hoefler&Co, Fontsmith, URW *(verify)*)
- Classics: **Helvetica Now** (with Micro/Text/Display optical sizes; much better than old Helvetica for UI), **Neue Haas Grotesk**, **Avenir Next**, **Frutiger**, **Univers Next**, **Futura**, **Gill Sans Nova**, **DIN Next**, **Neue Frutiger World** (multi-script).
- Access: Monotype Fonts subscription for teams, **MyFonts** marketplace (Monotype-owned) for single licenses. Enterprise agreements are common in large companies, so ask the brand team before licensing anything new.
- Notes: the classics are safe but generic. Use the *Now/Next/Nova* revisions, which have better spacing, weights and language support than the originals.

### Adobe Fonts
- Included with Creative Cloud. Covers desktop + web *(web projects served via Adobe's service)*. **Not** suitable for native app embedding. Check the Adobe Fonts licensing FAQ.
- Adobe originals with open licenses: **Source Sans 3 / Source Serif 4 / Source Code Pro** (OFL).

### Google Fonts (all free; mostly OFL)
Curated *quality* picks only. Many Google Fonts are mediocre.

| Role | Picks | Why |
|---|---|---|
| UI sans (neutral) | **Inter** (+ Inter Display via opsz in v4), **IBM Plex Sans**, **Geist** (Vercel, 2023), **Public Sans** (USWDS), **Roboto Flex** | Big x-height, tabular figures, many weights, variable |
| UI sans (warmer/friendlier) | **DM Sans**, **Manrope**, **Plus Jakarta Sans**, **Figtree**, **Instrument Sans**, **Onest**, **Hanken Grotesk**, **Schibsted Grotesk** | Personality without hurting UI legibility |
| Accessibility-first | **Atkinson Hyperlegible** (Braille Institute, 2019) and **Atkinson Hyperlegible Next** *(2025; verify)* | Maximally distinct letterforms |
| Reading serif | **Source Serif 4**, **Literata** (designed for Google Play Books), **Newsreader** (Production Type), **Spectral**, **Crimson Pro**, **Lora** | Screen-tuned. Literata and Newsreader have optical sizes |
| Display serif | **Fraunces** (variable "wonk"/soft axes), **Instrument Serif**, **Playfair Display** (overused), **DM Serif Display**, **Young Serif** | |
| Mono | **JetBrains Mono**, **IBM Plex Mono**, **Geist Mono**, **Commit Mono** *(not on Google Fonts; OFL)*, **Fira Code**, **Source Code Pro** | Distinct 0/O, l/1; ligatures optional |
| Variable showcase | **Recursive** (sans ↔ mono, casual axis), **Roboto Flex**, **Fraunces**, **Anybody** | |
| Multi-script | **Noto** family (Sans/Serif for 1,000+ languages) | Fallback for global apps |

### Fontshare (Indian Type Foundry, free)
- **Satoshi**, **General Sans**, **Switzer**, **Cabinet Grotesk**, **Clash Display**, **Supreme**, **Sentient**, **Gambetta**, **Erode**. Good-quality free alternatives to trendy paid grotesks. Check the Fontshare license page for each family.

### System and platform fonts
- **Apple:** SF Pro (Text/Display/Rounded, plus width variants), SF Compact (watchOS), SF Mono, New York (serif). Use them via SwiftUI text styles, and `system-ui` on the web.
- **Google/Android:** Roboto, Roboto Flex, **Google Sans** (proprietary to Google, not available for third-party products). For a similar feel, use Roboto Flex, Figtree or Outfit.
- **Microsoft:** Segoe UI Variable (Windows 11). Reference it in system stacks only.

## 5. Where to find references (research, not downloads)

- **Fonts In Use** (fontsinuse.com): an archive of real-world typography indexed by typeface, format and industry. Best for answering "who has used this font, and how?"
- **Typewolf** (typewolf.com, Jeremiah Shoaf): site-of-the-day type pairings, "favorite fonts" lists and free-alternative guides.
- **Typography.com, Klim, Commercial Type and Grilli microsites**: foundry essays explain the design intent of each family.
- **Google Fonts Knowledge** (fonts.google.com/knowledge): a free, well-sourced primer on type and variable fonts.
- **Butterick's Practical Typography**: free, opinionated rules.
- **Wakamai Fondue** (wakamaifondue.com): drop in a font file to see its OpenType features and axes.
- **v-fonts.com**: a variable fonts showcase.
- **Typecast-like testing:** set your real UI strings (prices, names, error messages) in the candidate font in Figma or the browser. Never decide on "The quick brown fox".
- Galleries for type in context: Awwwards, Siteinspire, Godly, Minimal Gallery, Lapa Ninja, Mobbin (apps) — see the inspiration library reference if present.

## 6. Decision recipes

**Dense SaaS / B2B tool:** Inter or Geist (free), or Söhne / Untitled Sans (premium). One family, 400/500/600, tabular figures on, 14px base on desktop.

**Consumer mobile app (iOS-first):** SF Pro via system text styles. Add a brand display face only for large titles and onboarding. Check that the display face has app-embedding rights.

**Consumer app (cross-platform brand):** a friendly grotesk with an app license (GT Walsheim, Graphik, or free DM Sans / Plus Jakarta). Pair it with the platform system font as a fallback for long text if needed.

**Editorial / reading product:** a reading serif with optical sizes (Tiempos, Literata, Newsreader) at 18–21px, with a grotesk for UI chrome.

**Marketing / landing page:** one expressive display face (licensed for web and ads) plus a neutral text face. Make the display face do the brand work. Don't add a third family.

**Data-heavy / finance:** a face with excellent tabular figures and distinct numerals (Inter with `tnum` + `ss01`/`cv` alternates, IBM Plex, Frere-Jones Retina for extreme sizes).

**Accessibility-critical (health, government, older users):** Atkinson Hyperlegible, Public Sans or system fonts; 18px+ body.

## 7. Font QA before committing (10-minute test)

1. Glyph check: `Il1| O0 rn m 6b 9g`, € £ ¥ ₹ ₺, currency in your markets, accented names (Łukasz, Nguyễn, Søren), emoji fallback.
2. Figures: `tnum` and `pnum` present? Does the zero need a slash (`zero` feature)?
3. Weights: check 400/500/600/700 at 12, 14, 16, 24 and 48px on a 1x display and on Windows.
4. Dark mode: does regular look too bold? Is a grade axis or 450 weight available?
5. File size: WOFF2 subset per weight; variable vs statics.
6. License: desktop + web + app + ads all covered? Who owns the license (company, not a personal account)?
7. Fallback metrics: generate `size-adjust` overrides, or use `next/font`.
8. Overuse check: search Fonts In Use / Typewolf. Is it the "default trendy" face this year?
